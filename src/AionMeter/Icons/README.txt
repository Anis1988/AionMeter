Custom class icons
==================

Aion Meter draws a coloured badge for each class. To use your own icons,
put PNG files in this folder named after the class, for example:

  Gladiator.png   Templar.png     Assassin.png    Ranger.png
  Sorcerer.png    Spiritmaster.png Cleric.png     Chanter.png
  Gunner.png      Songweaver.png  Aethertech.png  Unknown.png

Square images work best (32x32 or 64x64). Restart Aion Meter after adding them.
